เริ่มใช้สมุดการเงินบนคลาวด์

หน้าเว็บพร้อมแล้ว แต่ยังต้องเชื่อมโปรเจกต์ Supabase ของคุณเพื่อเปิดล็อกอินและซิงก์

1. สร้างโปรเจกต์ Supabase

เปิด Supabase Dashboard สร้างโปรเจกต์ แล้วรันไฟล์ SQL ในโฟลเดอร์ supabase/migrations ของซอร์สโค้ด

2. สร้างบัญชีเข้าเว็บ

ใน Authentication → Users เพิ่มอีเมลของคุณและตั้งรหัสผ่านเอง ปิดการสมัครใหม่หากใช้คนเดียว

3. ตั้งค่าบน GitHub

ใส่ Project URL และ Publishable key เป็น Variables ชื่อ SUPABASE_URL และ SUPABASE_PUBLISHABLE_KEY เปิด Pages แบบ GitHub Actions แล้ว Deploy

4. นำเข้าข้อมูลและเปิดอีกเครื่อง

เข้าสู่ระบบ นำเข้า JSON จากเว็บเดิม แล้วรอ “ซิงก์แล้ว” จากนั้นเปิดลิงก์เดียวกันบนมือถือและใช้บัญชีอีเมลเดียวกัน

Publishable key ใช้ในหน้าเว็บได้ ส่วน secret key, service_role และรหัสผ่านฐานข้อมูลห้ามใส่ในเว็บไซต์

ขั้นตอนละเอียดและวิธีตั้งอีเมลกู้รหัสผ่านอยู่ในไฟล์ SETUP-SUPABASE.md ที่ให้มาพร้อมซอร์สโค้ด
